# AutoFolio 실행

1. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 `extension` 폴더를 선택합니다.
3. 확장 아이콘의 **내 이력 편집**에서 인적사항, 학력, 경력, 자격증, 어학, 수상, 활동·경험, 프로젝트를 저장합니다. 항목은 여러 개 추가할 수 있습니다.
4. 지원서 페이지에서 확장을 열고 **현재 페이지 분석**을 누릅니다. 각 칸에 연결된 이력 값을 검토하거나 바꾼 뒤 **모두 채우기**를 누릅니다. **하나씩 채우기**를 누르면 지원서 페이지 오른쪽 아래 바에서 칸마다 넣을 값을 보고 채우기·건너뛰기·이전을 고를 수 있습니다. 채운 내용은 **되돌리기**로 입력 단위로 되돌립니다.
5. 입력 확인 결과와 실제 지원서를 검토하고 제출은 직접 수행합니다.

설치 의존성은 없습니다. 이력은 Chrome 확장 프로그램의 로컬 저장소에 보관합니다.

확장 프로그램을 삭제하면 저장소도 지워집니다. 이력 페이지의 **파일로 내려받기**로 `autofolio-이력-날짜.json`을 받아 두고, 재설치나 다른 PC에서는 **파일에서 불러오기**로 복원하세요. 이 파일에는 개인정보가 들어 있습니다. 저장소 폴더 안에 두더라도 `.gitignore`가 커밋을 막지만, 공유하지 마세요.
사용자가 입력을 실행할 때 확인한 필드 의미 매핑은 사이트별로 저장해 다음 분석에서 재사용합니다.

## 로컬 Laya 사용

Laya의 로컬 서버를 실행한 뒤 팝업에서 **로컬 Laya로 모르는 칸 분석**을 켭니다. Laya는 규칙으로 해석되지 않은 필드의 의미만 제안합니다. 제안은 팝업에서 사용자가 확인하고 수정할 수 있습니다. 서버가 없어도 규칙 기반 매핑과 수동 선택은 작동합니다.

```sh
pip install "laya[serve]"
laya-serve
```

확장은 `http://127.0.0.1:8000/v1/systemone`에 요청합니다. Laya 실행 환경에서 다른 주소를 사용한다면 `popup.js`의 주소를 바꿔야 합니다. 사용자의 이력 값은 Laya에 보내지 않고 필드 설명만 보냅니다.

## 로그와 진단 기록

- **콘솔 로그**: 지원서 페이지에서 F12 → Console을 열면 `[AutoFolio]`로 시작하는 줄에 찾은 입력칸 표와 칸별 입력 결과(`filled`/`review`/`failed`/`skipped`)가 나옵니다.
- **진단 기록**: 분석·입력을 할 때마다 최근 20회가 저장됩니다. 팝업 아래 **기록 내려받기**를 누르면 `autofolio-진단기록-날짜.json`을 받습니다. 기록에는 페이지 주소(쿼리 제외), 입력칸 라벨·섹션·종류, 제안한 매핑과 사용자가 고른 매핑, 결과가 들어갑니다.
- 저장한 이력 값은 기록하지 않습니다. 다만 검색형 칸의 결과 설명에는 화면에 뜬 후보 이름(예: 학교명)이 들어갈 수 있으니 공유 전에 한 번 확인하세요.

실제 사이트에서 잘 안 채워지는 칸이 있으면 이 기록 파일을 주면 원인을 찾을 수 있습니다.

## 현재 지원 범위

값은 칸의 placeholder·안내 글자에 있는 형식이나 예시(`010-1234-5678`, `YYYY.MM.DD`, `HONG GILDONG`)에 맞춰 넣습니다. 전화번호·이메일·생년월일처럼 여러 칸으로 나뉜 항목은 한 항목으로 보고 나눠 넣습니다.

일반 텍스트, 날짜·월 입력, 기본 `select`, 라디오·체크박스, `contenteditable`을 감지합니다.

검색형 입력(`role="combobox"`, `aria-autocomplete`, `datalist`)은 저장된 값을 입력한 뒤 나타난 결과 중 하나를 고릅니다. 이름이 같거나 `(본교)`처럼 괄호 설명만 다른 결과가 **하나일 때만** 자동으로 선택합니다. 캠퍼스가 여러 개이거나 비슷한 결과만 있으면 선택하지 않고 후보를 보여 주며 `?`로 표시합니다. 이때는 직접 고르세요.

`키워드 입력 후 Enter` 방식의 검색창은 Enter를 눌러 옆에 뜬 결과에서 고릅니다. 사이트가 실제 Enter 키 코드를 확인하므로 페이지 안에서 Enter를 누르는 `page-bridge.js`를 함께 넣습니다.

자격증처럼 `+` 버튼으로 줄을 늘리는 항목은 저장된 개수만큼 줄을 추가하고(최대 10줄), N번째 줄에 N번째 항목을 기본으로 고릅니다. 삭제·초기화 버튼은 누르지 않습니다. 자격증을 고른 뒤 열리는 발급기관·취득일 칸은 **다시 분석**하면 채울 수 있습니다.

검색 버튼으로 여는 별도 팝업 창은 아직 직접 선택해야 합니다. 모델의 분류가 맞더라도 페이지 입력에 실패할 수 있으므로 결과를 반드시 확인하세요.

개발 검증: 저장소 루트에서 `npm test`. 단위 테스트와 함께 `tests/form-fixture.html`(DOM 수집·입력·날짜 변환·검색형 선택 샘플)을 헤드리스 Chrome으로 실행합니다. Chrome 위치가 다르면 `CHROME_PATH`를 지정하세요.
